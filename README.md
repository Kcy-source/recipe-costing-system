- Supabase RLS：未登录无法读取或修改成本资料

## Costing 逻辑

原材料实际单位成本 = 采购价 ÷ (基础数量 × 净料率)

单项配料成本 = 使用量 × 实际单位成本 ÷ (1 - 损耗率)

每份成本 = 食谱总配料成本 ÷ 出品数量

Food Cost % = 每份成本 ÷ 售价 × 100

毛利 = 售价 - 每份成本

## 配方 / 半成品

- 在独立的「配方 / 半成品」页面建立味水、酱料、上汤等自制项目；记录原材料、每批实际产出量、单位及做法。
- 配方单位成本 = 当前原材料净成本总和 ÷ 熬煮、过滤后的实际可用产出量。
- 食谱配料可对应原材料或配方。输入味水用量后，其成本计入菜品；原材料采购价或配方产出改变后自动重新计算。
- 单位可自行填写。g / kg / 克 / 公斤、ml / L / 毫升 / 升支持同类换算；其他自填单位须一致。单位不匹配、未对应或配方资料不完整时显示「待完成」。
- 被菜品使用的配方不能删除。配方与食谱保存使用事务，失败时保留原资料；过期的编辑会被拒绝，避免覆盖其他人的更新。
- Excel 导出包含配方、配方原材料和菜品调用明细。

数据库变更来源：`database/preparations.sql`，使用现有的已启用账号权限和 RLS。成本计算验证：`node tests/costing-model.test.cjs`。
